# Employee-System
# Employee Management System (OOP-Based Python Project)

A beginner-friendly Python project built using Object-Oriented Programming (OOP) concepts.

This project demonstrates:
- Classes and Objects
- Inheritance
- Constructors
- Method usage
- Code reusability using `super()`

---

## 📌 Project Overview

The project contains two classes:

### 1. Employee Class
Stores:
- Role
- Department
- Salary

Includes a method:
- `showDetails()` → displays employee details

---

### 2. Engineer Class
The `Engineer` class inherits from the `Employee` class.

Additional attributes:
- Name
- Age

Default inherited values:
- Role → Engineer
- Department → IT
- Salary → 45000

This demonstrates:
- Inheritance
- Parent-child class relationship
- Use of `super()`

---

## 🛠 Concepts Used

- Python OOP
- Classes & Objects
- Inheritance
- Constructors (`__init__`)

- `super()` Function
